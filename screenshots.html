Health Endpoint — HTTP 200 OK

GET /health · Polled by ALB every 15 seconds
🔒pakweather-alb-1234567890.ap-south-1.elb.amazonaws.com/health
💚

`GET /health` returns JSON with instance metadata. The ALB uses this endpoint to determine routing eligibility. Any non-200 response causes the ALB to stop sending traffic to that instance within 3 check intervals (45 seconds).
